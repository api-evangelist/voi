# Voi

> Voi Technology is a Swedish micromobility company operating shared e-scooters and e-bikes in more than 100 cities across Europe. For partners and cities it publishes a MaaS Partner API for completing full rental journeys, an MDS 0.4 provider API, and a flavored GBFS feed. No /llms.txt is published by the provider; this file was generated by API Evangelist from the catalog on 2026-07-21.

Authentication: the MaaS Partner API uses an X-Auth-Token header issued at partner signup; MDS and GBFS use OAuth 2.0 client credentials (POST https://mds.voiapp.io/token, bearer tokens, 900s expiry). All APIs require partner onboarding - there is no self-service signup.

## APIs

- [Voi MaaS Partner API](https://github.com/voiapp/partner-api-docs/blob/gh-pages/maas-pro.md): Register users, discover vehicles by zone, get per-vehicle pricing, start/end rentals, fetch GeoJSON zone areas. Base URL https://partners.voiapp.io/v1
- [Voi MDS Provider API](https://github.com/voiapp/partner-api-docs/blob/gh-pages/maas-light.md): Mobility Data Specification 0.4 trips, status_changes, and events per operational zone. Base URL https://mds.voiapp.io
- [Voi GBFS API](https://github.com/voiapp/partner-api-docs/blob/gh-pages/maas-light.md): gbfs.json, system_information, free_bike_status per zone, with X-Voigbfs-Ext battery extension. Base URL https://mds.voiapp.io/v1/gbfs
